# GigaVibeMiptCode

Консольный ИИ-ассистент для общения с LLM через OpenAI-compatible API. Проект поддерживает работу со всеми OpenAI-совместимым API(например Ollama)

## Функционал

- Чат с LLM в консоли.
- Хранение истории сообщений.
- Ограничение контекста по числу сообщений и числу символов.
- Настройка через `config.yaml` и переменные окружения.
- Подстановка содержимого файлов через `@::path/to/file::`.
- Команда `/reset` для очистки истории.
- Команда `/file_chunk` для обработки файла по частям.
- Streaming response: ответ модели выводится постепенно во время генерации.

## Структура проекта

- main.py — главный консольный цикл: читает ввод, парсит, передает дальше.
- src/commands.py — команды приложения и распределение команд.
- src/config.py — загрузка настроек из config.yaml и переменных окружения.
- src/llm.py — общение с моделью.
- src/expanding_references.py — работа с @::file::, чтение прикрепленных файлов.
- src/file_chunk.py — режим обработки файла по чанкам.
- requirements.txt — зависимости.

## Установка

Из папки проекта установите зависимости:

```bash
pip install -r requirements.txt
```

Для локальной модели можно использовать Ollama. Например:

```bash
ollama pull qwen2.5:1.5b
```

## Настройка

Создайте файл `config.yaml` рядом с `main.py`.

Пример конфигурации:

```yaml
api_key: ollama
api_host: http://localhost:11434/v1/
model: qwen2.5:1.5b
limit_message: 20
limit_chars: 2000
temperature: 0.1
system_prompt: You are a helpful assistant. Use previous messages in the conversation to answer follow-up questions.
```

Для локальной Ollama настоящий токен не нужен, но для работы библиотеки `openai` нужен непустой `api_key`, поэтому можно указать `ollama` как заглушку.

## Переменные окружения

Настройки также можно задать через переменные окружения. Они имеют приоритет над `config.yaml`.

```bash
export API_KEY="ollama"
export API_HOST="http://localhost:11434/v1/"
export MODEL="qwen2.5:1.5b"
export LIMIT_MESSAGE="20"
export LIMIT_CHARS="2000"
export TEMPERATURE="0.1"
```

`system_prompt` задается только через `config.yaml`.

## Запуск

```bash
python3 main.py
```

Приложение загружает конфиг один раз при старте. Если изменить `config.yaml`, нужно перезапустить программу.

## Команды

- `/help` - показать список команд.
- `/exit`, `/quit` - выйти из приложения.
- `\q` - выйти из приложения, если был активирован режим file_chunk, то выходит только из него.
- `/reset` - очистить историю сообщений.
- `/history` - показать текущую историю сообщений.
- `/file_chunk` - запустить режим обработки файла по частям.

Обычный текст без `/` отправляется в LLM как сообщение пользователя.

Для выхода из приложения или режима file_chunk, а также для прерывания ответа модели можно использовать Ctrl+C.

## Прикрепление файлов

Чтобы добавить содержимое текстового файла к запросу, используйте:

```text
Проверь код @::src/llm.py::
```

Можно использовать относительный или абсолютный путь. Относительный путь считается от папки, из которой запущена программа. Максимальный размер файла - 5 МБ.

## Обработка файла по чанкам

Команда `/file_chunk` запускает интерактивный режим:

```text
/file_chunk
```

Программа попросит путь к файлу и prompt, который нужно применить к каждому фрагменту.

Флаги команды

- `paragraph=3` - объединять по 3 абзаца.
- `len=150` - делить по 150 символов.
- `-y` - обрабатывать чанки автоматически, без ожидания Enter между ними.

**Note** Можно использовать только один вид разделения: либо по абзацам, либо по длине.
**Note** По умолчанию идет деление по 1 абзацу, без автоматической обработки чанков

Команды внутри режима
- `\q` внутри режима - выйти из обработки файла.

В режиме `/file_chunk` каждый фрагмент отправляется в LLM отдельно. История обычного чата при этом не засоряется.
